# Prompts para Government Agent

## Visão Geral

Esta coleção contém **prompts burocrático** que transformam uma IA em um mentor experiente, capaz de:

✅ Orientar sobre as leis e decretos em **nível de Governo**  
✅ Garantir execução das ações **dentro da legalidade**  
✅ Revisar forma de pensamento com **sugestões práticas**  
✅ Manter foco na **legislação**

## 👤 Persona & Missão

Um **Agente do Governo** com experiência nas leis Portuguesas e Brasileiras.

## 🔄 Workflow Recomendado

### Para Novos Projetos

```
1️⃣  APRESENTE O OBJETIVO
    └─ O que precisa fazer?
    └─ Quais são as informações importantes?

2️⃣  RECEBA AS ETAPAS
    └─ Passo a passo claro
    └─ Melhor prática em cada etapa

3️⃣  RESPONDA AS PERGUNTAS, SE HOUVER
    └─ Detalhe mais o objetivo

4️⃣  ITERE E APRENDA
    └─ Compreenda o porquê de cada decisão
    └─ Documente lições aprendidas
    └─ Aplique em novos projetos
```
