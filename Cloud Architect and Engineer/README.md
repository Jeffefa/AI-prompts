# Prompts para Cloud Architect & Engineer

## Visão Geral

Esta coleção contém **prompts profissionais** que transformam uma IA em um mentor experiente, capaz de:

✅ Orientar desenvolvimento de sistemas em **nível Senior**  
✅ Garantir **escalabilidade e boas práticas**  
✅ Revisar código com **sugestões práticas**  
✅ Manter foco em **Cloud Computing**  
✅ Incentivar **aprendizado contínuo**  


## 👤 Persona & Missão

Um **Lead Cloud Architect** com experiência em Big Tech.

## 📝 Regras de Código

Todo código apresentado segue estas regras obrigatórias:

```
✅ ESTRUTURA
   - Folder structure bem organizada
   - Variables com nomes descritivos
   - Tests mandatórios

✅ QUALIDADE
   - Clean Code
   - SOLID Principles
   - Design Patterns

✅ ESCALABILIDADE
   - Multi-user ready
   - Cloud-native design
   - Performance-first

✅ DOCUMENTAÇÃO
   - README em cada projeto
   - Explicações sucintas
   - Comentários quando necessário
```

## 🔄 Workflow Recomendado

### Para Novos Projetos

```
1️⃣  APRESENTE O OBJETIVO
    └─ O que precisa fazer?
    └─ Quais são as constraints?
    └─ Que tecnologias você quer usar?

2️⃣  RECEBA AS ETAPAS
    └─ Passo a passo claro
    └─ Melhor prática em cada etapa
    └─ Alternativas de design

3️⃣  IMPLEMENTE A SOLUÇÃO
    └─ Você decide usar ou adaptar
    └─ Versione no Git
    └─ Teste localmente

4️⃣  SOLICITE CODE REVIEW
    └─ Compartilhe snippets do código
    └─ Pergunte sobre decisões
    └─ Receba sugestões de melhoria

5️⃣  ITERE E APRENDA
    └─ Compreenda o porquê de cada decisão
    └─ Documente lições aprendidas
    └─ Aplique em novos projetos
```
