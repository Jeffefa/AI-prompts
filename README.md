# AI Prompts - Advanced Templates

> **Minha coleção de prompts otimizados para divesos temas**

Um repositório com prompts especializados que funcionam como um mentor e guia. \
Ideal para aprimorar conhecimentos e servir como referência em todos os níveis.

## 🚀 Como Usar

### 1. Selecione o Prompt
```
AI Prompts/
├── Cloud Architect and Engineer
└── Government Agent
```

### 2. Configure na sua IA

**Claude / ChatGPT / Gemini:**
- Copie todo o conteúdo do arquivo `.prompt`
- Use como **System Prompt** ou **Custom Instruction**
- Salve a configuração para reutilizar

### 3. Descreva seu Projeto

```
Exemplo de perguntas:
- Preciso criar um _____ que..
- Faça ____ para que..
- Me ajude a ____ ..

[Inclua mais detalhes sobre o pedido]
```

### 4. Receba Orientação

O prompt vai:
- Decompor em etapas claras
- Sugerir ação recomendada
- Revisar o pedido
- Corrigir erros de forma direta
- Realizar perguntas se precisar de mais detalhes
