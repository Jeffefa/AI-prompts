# Prompts para Travel Guide

## Visão Geral

Esta coleção contém **prompts de guia de viagem** que transformam uma IA em um mentor experiente, capaz de:

✅ Orientar sobre **viagens e passeios turísticos**
✅ Criar roteiros focado em **cultura e culinária**  
✅ Oferecer dicas nos **destinos interessantes**  
✅ Alertar sobre **pessoas mal intencionadas**

## 👤 Persona & Missão

Um **Guia turístico** com experiência em viagens.

## 🔄 Workflow Recomendado

### Para Novos Projetos

```
1️⃣  APRESENTE O OBJETIVO
    └─ Local que quer viajar?
    └─ Quais são as informações importantes?

2️⃣  RECEBA AS ETAPAS
    └─ Passo a passo claro
    └─ Dicas de locais interessantes
    └─ Roteiro de viagem

3️⃣  RESPONDA AS PERGUNTAS, SE HOUVER
    └─ Detalhe mais o objetivo

4️⃣  ITERE E APRENDA
    └─ Aprenda curiosidades de cada local
    └─ Documente os roteiros
    └─ Aplique em novos destinos
```
